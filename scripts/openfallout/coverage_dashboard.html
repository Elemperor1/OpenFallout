OpenFallout engine coverage*

By library

*What is counted

The unit
One thing the games define and the engine has to answer to: a script command (615, from the tables read out of the two executables), a function of a script extender plugin (from the plugin's DLL), a record type of the two base plugins, a menu file of the games (menus/*.xml), a perk entry point (from the editor) or an animation group (from the tables of the executables). Every unit has at least its name from one of those tables.
Read
What the unit does, or for a menu how it is laid out, has been read from the executables or the games' data files, and the read is on record: a line in the tracker (reads.csv, or the read column of the menu and perk tables) with where it was found, or for a record type a loader that parses it. The name and code alone do not count. A unit the engine implements but nobody wrote down a read of is not counted here; that gap is what the tracker is for.
Implemented: done
The engine has it: a handler is registered for the command or function, the record is loaded and kept in the record store, a perk entry point is applied by some code, the engine picks animation files by the group's name. Done means built, not checked against the games; the audit in docs/openfallout lists what nobody has verified.
Implemented: stand-in
The engine takes it in and does nothing with it, or gives a fixed answer. A record is a stand-in when it is loaded and then dropped. A menu is a stand-in when one of the engine's own screens (Lua, on Morrowind's widgets) does its job; it is done only when the game's own menu file is drawn.
Not done, not read
No handler (the engine reports it once and carries on), no record store, no code that applies the entry point, no screen; or, in the Read colouring, no read on record.
Left out
Ten perk entry points of the editor's table that no code of the executable calls and no perk uses. The games' interface textures, NIF block types and the functions of the executables themselves are not counted yet.
Scopes
The games leaves out the extender functions, which only mods use. Tale of Two Wastelands adds back the 139 extender codes its scripts call.
Keeping it right
The tracker lives in docs/openfallout/coverage/tracker. When a round reads something, add a line to reads.csv (or flip the read column) with its evidence; when a screen or a rule lands, the page follows from the source or the menu table.
